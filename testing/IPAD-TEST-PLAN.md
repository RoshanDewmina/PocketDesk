# B7 universal iPad hands test — 15 minutes

Run on the borrowed iPad Air 5 after the orchestrator integrates and installs the reviewed B7 candidate. This lane installs nothing and never operates the installed host or real devices. Use a disposable TextEdit document and a harmless file. Record build, iPadOS, Mac display size, and available keyboard/trackpad/Pencil.

Simulator screenshots prove rendering and fixture behavior. They do not prove Stage Manager focus, menu-bar arbitration, hardware input, real transfers, latency, or thermal performance.

| Time | Check | Exact steps and pass criteria |
| --- | --- | --- |
| 0–3 min | Home and window bands | Open portrait: Mac/Connect leading, utilities trailing, no clipped text. Rotate landscape. Connect; portrait has a complete Fit picture above a trackpad, landscape a large picture. Resize through ⅓, ½, ⅔ Split View and tall/wide Stage Manager windows: compact width uses the bottom five-dot handle; regular width uses the top pill. Drag slowly near square: layout does not alternate repeatedly. |
| 3–5 min | Top anchor and system edge | In landscape tap the pill once: dock drops below it. Double tap: keyboard opens, dock stays closed. Idle two seconds: five dots; reconnect/busy notices remain expanded. Reveal iPadOS's menu bar from the top edge, then recover the pill. Pass: system gestures remain reachable, no unintended Mac click or swipe-triggered pill action. Keys and End session remain reachable, including Full Keyboard Access. |
| 5–7 min | Keyboard and picture | In portrait open the software keyboard: picture position/size stays fixed, keyboard occupies the pad. Landscape Fit re-fits above the keyboard; dismiss restores it. With hardware keyboard, Keys opens only the text field, no redundant shortcut bar. Type, hold/release arrow/Delete, ⌘C/⌘V, ⌘W/⌘M, and ⌃⌥Tab: intended keys reach the Mac; no stuck modifier/repeat after focus loss or disconnect. iPadOS-owned ⌘Tab/Space/H remain system shortcuts. |
| 7–10 min | **Measure focus before changing policy** | While collecting the device log (`com.roshan.PocketDesk`, category `iPadFocus`), switch focus between Farside and another Stage Manager/Split View window three times. Record each `scenePhase` and whether picture/audio stop or shielding appears. Repeat Control Center, screen recording, and full backgrounding. Input must stop/release when focus leaves; recording/background must conceal private content. If ordinary focus loss produces `.inactive`, the spec's regular-window picture/audio/hold/PiP policy remains an integration gate: implement it only after distinguishing these measured paths, then rerun. The B7 source deliberately retains existing shielding/audio/background behavior until this evidence exists. |
| 10–12 min | Trackpad and mouse | Move/click/right-click/scroll on picture and pad, including while dock is open. Click targets match the shown Mac pointer. In full screen explicitly Lock relative mouse, move, then Escape; repeat disconnect/background/End. Every escape releases pointer lock and modifiers. Never auto-lock. |
| 12–14 min | Drop to send | In Split View or Stage Manager drag one harmless file from Files onto the session. Pass: one transfer capsule, exact filename/content on Mac, Cancel works. Try two files, a transfer already in flight, and a disconnected/view-only session: explicit refusal, no silent partial send, no unauthorized transfer. This is a direct user-initiated send using existing file-channel/scope admission. |
| 14–15 min | Pencil and recovery | If available, hover/contact/pressure/palm-rest on a disposable drawing document, lift outside the picture and End mid-stroke. Pencil works with no setting; no stuck stroke, palm drawing, or stale input. Background 20 seconds and return: resume or clean explicit ending, never unshield a hidden session automatically. |

Record any failure with step, window band, scene phase, and screenshot if useful. Attach device logs and relevant host statistics collected by the orchestrator. No physical acceptance is inferred from this document.

App Store checklist: universal iPhone/iPad 1.0; use the simulator 13-inch iPad captures after final review; **Make this app available on Mac OFF** (owner default). Do not enable multiple windows or external-display support. Portal changes/submission belong to the orchestrator's approved release step.

The spec explicitly removes **Apple Pencil input**, while explicitly retaining Mini map, Lock relative mouse, and the distinct ⌃⌥ remap toggle. Although the task mentions two removed iPad-only controls, the reviewed spec identifies only this one for deletion; do not remove one of its explicitly retained controls by guessing.
