## Implementation to verify

Approved trust is saved before the bounded permission wait. Optional sealed setup status postpones media and physical LAN proof while capture permission/catalog readiness is missing; repeated status polls do not extend the fixed five-minute wait. Accessibility absence remains view only. Lock, sleep, revoked grants, route expiry and failed capture/proof retain their safety boundaries.

Fresh enrollment capability travels in the optional proof field outside the existing hashed request transcript; reconnect uses an additive handshake field. A sealed acceptance acknowledgment gates the new status, so an older host does not leave a newer phone waiting for unsupported messages.

Big Text waits while Mac setup is open; after Done, the candidate bounds its temporary settling cover to one second, with ordinary privacy/freshness admission still authoritative. Healthy single-display owner control can finish setup by clicking Done remotely; view-only/no-shared-display/multiple-display cases retain a local Done fallback. “Slide to move” then “Tap to click” teach on the live surface; a posted-click receipt finishes the click hint, including Done followed by deferred settling. Manual coach replay remains available.
