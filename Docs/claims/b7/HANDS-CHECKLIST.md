## One ~20-minute active sitting

Have iPhone + iPad and unlocked Mac on the same Wi-Fi. Prepare an unsaved TextEdit document and a Finder window; avoid sensitive screen content. Keep existing pairing. For the fresh-approval check, use the iPad only if it is still unpaired; otherwise schedule an isolated spare-client pairing without deleting trusted devices.

## Long-session tail — cannot fit honestly into 20 minutes

C5 needs a continuous **at least 35-minute** native local session. After the sitting, explicitly Resume Sharing on the Mac and connect a fresh native local session for this tail (or start beforehand on a separate client only if concurrent connections are supported). Leave phone foreground/awake and Mac unlocked, same LAN, PiP off; record session start/end and build numbers. At minutes 0, 16, 31 and 35 move pointer and type distinct markers in TextEdit. Pass: same session remains live beyond 35 minutes, image changes and input lands, with no reconnect/re-pair and no payment/trial dependence. At the end perform Stop Sharing if not already checked. A 10-second accelerated lease test or standalone media loopback does **not** unlock C5. Restrict wording to native same-Wi-Fi use: the browser client has a ten-minute cap.

## Separate gates, not part of the sitting

- Minimum-OS runtime acceptance: C12 config/binary minimum is26, but a real Mac already running macOS26 is needed to prove that runtime. The shared Mac on27 cannot supply this evidence. iOS26 minimum acceptance is also separate from these iOS27 simulator checks.
- C8 complete accessibility/label acceptance: the sitting checks a few common controls. A separate documented pass must cover each supported device and the relevant feature criteria, including accessible remote-Mac common tasks, before declaring Supports or claiming a completed full-app audit. Voice Control and media accessibility criteria are not assessed by the quick VoiceOver triage.
- Duo half-folded layout: real compatible device/runtime or a successfully booted compatible simulator plus later physical input/alignment acceptance. Until available, remove the Duo promise; an iPad check cannot substitute.
- C6/C7/C9/C10: authorized ASC/provider/release verification (paid agreement, actual purchasable plan, cellular/relay, countries, notarized download/site/uploaded build, saved listing text). This lane has no publication/account authorization and makes no live ASC edits.
- C11: owner decision to name iPhone Mirroring; technical direction is supported by Apple, but owner approval is not supplied by a simulator.
